# 📍 NearServe — Real-Time Hyperlocal Service Network (Frontend)

This directory contains the React 18 + TypeScript + Vite frontend for **NearServe**.

## Quick Commands

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build production bundle
npm run build
```

Refer to the main [`README.md`](../README.md) in the root directory for detailed feature documentation, API breakdowns, and architecture overview.
